# Wordletr 🎯

Türkçe günlük kelime tahmin oyunu.

## Özellikler

- 🎮 Günlük kelime tahmini
- 📊 4-7 harf arası kelime uzunluğu seçimi
- 🌙 Karanlık/Aydınlık tema
- 📈 Kişisel istatistikler
- 📤 Sonuç paylaşımı
- 📱 Mobil uyumlu

## Kurulum

```bash
npm install
npm run dev
```

## Teknolojiler

- Next.js 14
- Tailwind CSS
- localStorage
